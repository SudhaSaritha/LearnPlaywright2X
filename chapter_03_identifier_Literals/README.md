# Chapter 3 - Identifiers & Literals

This chapter covers **JavaScript identifiers** — the rules for naming variables, functions, and other tokens in JavaScript.

## Topics Covered

- **Identifier Rules** (`01_Identifier_Rules.js`, `06_Identifier_Rules.js`)
  - Valid characters: letters, `_`, `$`, and digits (not at the start)
  - Cannot be a reserved keyword
  - Case-sensitive
  - Unicode letters (ES6+)
- **Naming Conventions** (`07_Identifier_Part2.js`)
  - camelCase, PascalCase, snake_case, UPPER_SNAKE_CASE, Hungarian notation, etc.
- **Comments** (`08_Comments.js`)
  - Single-line (`//`) and multi-line (`/* */`) comments
