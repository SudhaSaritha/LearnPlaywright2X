# LearnPlaywright2X

A hands-on learning repository for **Playwright** automation with **JavaScript** fundamentals.

## Structure

| Chapter | Contents |
|---------|----------|
| `chapter_01_Basics` | JavaScript basics - `console.log`, functions, loops |
| `chapter_02_Javascript_Concepts` | Variables, `var`/`let`/`const` |
| `chapter_03_identifier_Literals` | Identifier rules, naming conventions, comments |

## Prerequisites

- [Node.js](https://nodejs.org/)
- [Playwright](https://playwright.dev/)
